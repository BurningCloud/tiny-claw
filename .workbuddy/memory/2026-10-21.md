# 2026-10-21

## 修复：claw 启动报 Event.__init__() missing 1 required positional argument: 'turn'

- 位置：`tiny_claw/apps/claw.py` `_amain()` 中记录 `SESSION_START` 事件处（约 183 行）。
- 原因：`observability/tracing.py` 的 `Event` dataclass 前四个字段 `session, turn, kind, detail` 无默认值（必填），
  而 claw.py 只传了 `session/kind/detail/ok`，漏了 `turn`。
- 修复：补 `turn=0`，与 `engine/loop.py` 中 `_compact_if_needed()` 记录 COMPACT 事件的约定一致
  （会话级、不属于任何轮次的事件统一用 turn=0）。
- 验证：`python -m unittest discover -s tests -q` → 27 tests OK。环境无 pytest，用 unittest 跑。
